# Windows installation

Mouse Engine RC3 is distributed as an x64 per-user application.

- Install root: %LOCALAPPDATA%\\Programs\\Mouse Engine
- User data: %LOCALAPPDATA%\\Mouse Engine
- Default mutation policy: denied
- Firmware flashing: disabled in the host contract

The installer must not delete user data during a normal uninstall. Use the explicit removal option only when user data deletion is intended.

Windows physical hardware and WebView2 Runtime validation remain external release gates.
